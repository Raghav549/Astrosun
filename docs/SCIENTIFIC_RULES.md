# Scientific Rules for AstroSun

## 1. Astronomy first
Whenever a feature concerns the actual sky, calculate the underlying astronomical state independently of the interpretation layer.

Examples: planetary longitude, right ascension/declination, altitude/azimuth, elongation, angular separation, illumination, rise/set, transit, eclipse geometry, orbital period, state vectors.

## 2. No scientific laundering
Do not convert a traditional Jyotisha statement into a scientific statement merely because the inputs use real astronomical positions.

## 3. Traceability
Every non-trivial scientific result should expose enough metadata to reproduce it: epoch, time scale, observer location, coordinate system, input source, algorithm/model version and numerical precision where available.

## 4. Uncertainty
Predictions should expose uncertainty or an accuracy class when the source model/data supports it. Do not display an unjustified precision.

## 5. Research answers
AI answers should cite retrieved research and clearly separate:
- established observation,
- deterministic calculation,
- model-dependent inference,
- hypothesis/open question,
- traditional/cultural interpretation.

## 6. Personal-life outputs
For life-oriented pages, recommendations should be framed as educational, reflective or traditional interpretations. The scientific engine may explain physical phenomena and provide evidence, but it must not fabricate a causal mechanism between planetary positions and individual outcomes.

## 7. Stones/minerals
A stone recommendation should always state whether its basis is mineralogical, physical/material, cultural/traditional, aesthetic or user preference. Claims of medical or guaranteed life effects require independently established evidence and must not be invented by the AI layer.
